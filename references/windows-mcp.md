# Windows MCP 排障参考

按当前需要只读对应小节。本文件是操作参考，参数以环境实际暴露的工具定义为准。

## 工具选取

| 需求 | 调用形态 |
| --- | --- |
| 初次观察、结构变化 | `Snapshot(use_ui_tree=false, use_vision=true, use_annotation=false)` |
| 全屏 / 局部复核 | `Screenshot()` / `Screenshot(region=[left,top,right,bottom])` |
| 切换观察到的目标窗口 | `App(mode="switch", name=实际窗口名称)` |
| 点选 / 悬停 | `Click(loc=[x,y])` / `Move(loc=[x,y])` |
| 滚动指定区域 | `Scroll(loc=[x,y], direction="down", wheel_times=适量)` |
| 确认用户控制状态 | `ControlStatus()` |
| 正常播放中等待 | `Wait(duration=30)`，按剩余时间调整 |
| 必要时读取页面文字 | `Snapshot(use_dom=true, use_vision=false)`，只保留相关文字 |

切换窗口、点击、滚动等按依赖顺序执行；不要并行发送输入。工具结果为失败时，先重新观察，避免对结果未知的动作重复点击。

## 坐标换算

- `Click` 等 `loc` 使用虚拟桌面坐标。UI 树若已提供屏幕坐标，不再乘截图缩放比例。
- 全屏预览：屏幕坐标 = 预览坐标 × 工具本次返回的比例。
- 裁剪预览：屏幕坐标 = 裁剪左上角坐标 + 预览局部坐标 × 本次比例。不要漏加裁剪原点。
- 例如全屏从 2560×1440 缩为 1920×1080，比例约 1.3333；这不是所有截图的固定比例。小区域截图可能为 1:1。
- 不沿用其他课程的坐标或固定裁剪区域。先实测任务点、播放器控制条和目录的位置，再取小区域。

## 倍速菜单和播放状态

先悬停在当前控制条或倍速按钮处；出现菜单后，按当前画面点 `2x`，再确认标签。若悬停没有唤出控制条，可点一次画面，观察是否已暂停，再按实际按钮恢复播放。

画面静止、截图相似或时间未变一次，都不足以判断暂停。结合播放/暂停按钮和相隔一段时间后的时间戳判断。若按钮显示“播放”，恢复；若显示“暂停”但时间不推进，检查缓冲或错误。经一次正常恢复仍无进展，记录阻塞，不循环点击。

预期剩余播放时间约为 `(总时长 − 当前进度) ÷ 实际倍速`；缓冲、网站记录延迟及各课完成规则可能使结果变长。完成状态优先于该估计，不能用估计倒推完成。

## 用户接管或中断

- 返回 `USER_CONTROL` 或 `state:"user"` 时停止输入和抢焦点操作。`Wait`、截图也可能被该工具拒绝。
- 使用宿主允许的非输入式计时等待后再读 `ControlStatus`；恢复 `ready` 后重新观察页面再继续。用户仍占用时继续让出控制，不高频重试。
- 用户明确停止后不再等待着自动恢复，不创建定时器、自动化或后台续做。向用户报告最后确认状态；只有用户重新要求继续才恢复。

## 完成状态延迟或矛盾

- 视频已播到末尾仍未变绿：分两轮各等待约 30 秒检查；必要时通过正常目录重新进入一次。仍无明确完成标记则记为“待核验”，继续其他授权项，收尾再复查，不无限等待或反复重播。
- 目录数字与视频独立状态不一致：检查同小节全部标签页和下方视频；以各独立任务点的实时标记为依据。正常重新进入后仍矛盾，报告具体差异，不直接宣布小节或整课完成。

## 遮挡、失焦、页面异常

- 笔记提示、AI 助教浮窗：按最新截图关闭普通提示或点击没有被遮挡的目录文字。不要沿用旧屏的落点。
- 截到别的窗口：用观察到的 Edge 窗口名重新切换，然后截图定位。
- 目录位置随滚动改变：滚动后重拍目录。处理完当前视频，还要检查同页下方其他视频。
- 出现空白或“enc 校验失败”：重新观察，可通过正常后退恢复；返回后重核课程、进度和倍速。不要向地址栏输入 `javascript:`，不要修改网站参数或课程记录。
- 需要登录、验证码或站点安全提示时，遵循宿主要求交由用户或使用被允许的方式处理，不擅自绕过。

## 收尾记录

完成结果只记已观察到的事实：课程/小节名、完成或未完成、待办和最后确认进度。不要把某次历史课程、章节、观看比例或课件等待时长固化为下一次运行的默认事实。
